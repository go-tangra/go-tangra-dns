# dns join bundle

Generated by the gateway (Gateway operations › Modules › dns › Add).

    docker compose up -d
    docker compose --profile metrics up -d   # optional: the dashboard's Prometheus

`private/` holds credentials (the single-use enrolment token, the bundle's
TLS keys); `.env` holds generated passwords and the KEK; `config.yaml` holds
the event-bus password you gave. Keep them on this host only, and back up the
`dns-db` volume together with `.env` (the KEK decrypts what the database
stores). The enrolment token is valid for the lifetime chosen in the wizard;
after the first start the module renews its identity itself.

The dns module joins the core's event bus (Valkey, TLS) as user `dns`: the
core's Valkey must accept that user from this host. Zone and record events go
to `platform:events:<tenant>` there, and the gateway fans them out to
signed-in browsers.

PowerDNS Authoritative and Recursor run here; their HTTP APIs stay on this
project's network (never published) and their API keys are generated on the
first start into the `dns-secrets` volume. Without a Docker socket, a
configuration save that changes a PowerDNS include file reports
`restart_required`: run `docker compose restart pdns-auth pdns-recursor`.
IPAM sync is off (it needs ipam's mesh address, which the wizard does not
fill in). For lcm's Freya DNS ACME provider, lcm on the core needs `dns` in
its discovery pointing at this host (port 9965) and `dns: { service: dns }`.
